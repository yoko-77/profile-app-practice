# profile-app-practice

## 概要

COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
profile.blade.phpを作成
ドメイン/profileページには氏名、年齢、趣味を表示

## 使用技術

- PHP 8.x
- Laravel 10.x
- Blade テンプレート
  sail

## 学んだこと

-ルーティング、コントローラー、ビューの簡易更新

- コントローラの趣味部分
  　複数趣味ありのため、配列記載することから
  　単数形hobbyから複数形記載hobbiesに修正
  　ビューでも複数形の記載に修正
  　※単数形でも動作するが、お作法に従って修正
